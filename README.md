# Сборник заданий ВУЦ

Полностью статичный сайт для подготовки к зачёту по двум предметам:
«Общевоенная подготовка» (устав) и «Общая тактика». Никакого сервера —
только HTML, CSS и JS, работает даже без интернета (кроме шрифтов).

## Структура сайта

```
index.html              — главная: предметы + домашние задания
error.html               — страница 404 для хостинга

shared/
  theme.css              — общий дизайн для всех страниц
  site.js                 — общие мелочи: звук, подсветка меню, утилиты
  deck-engine.js          — движок тем «термин ↔ определение»
                            (конспект / тренажёр / проверка знаний)

ustav/
  index.html              — хаб предмета «Общевоенная подготовка», по парам
  pogony.html              — игра «Погоны и звания» (отдельный движок,
                              самодостаточный файл — погоны рисуются SVG)
  vuc-order.html           — Пара 1 · структура и порядок в ВУЦ
  charters-history.html    — Пара 1 · история и назначение уставов
  ranks-command.html       — Пара 1 · должности, командование, численность
  rights-duties.html       — Пара 1 · права и общие обязанности
  relations.html           — Пара 1 · взаимоотношения между военнослужащими
  quartering.html          — Пара 2 · размещение военнослужащих
  duty-corps.html          — Пара 2 · суточный наряд воинской части
  stroevoy-terms.html      — Пара 2 · термины строевого устава (со схемами)
  stroevoy-duties.html     — Пара 2 · строевой устав: содержание и обязанности
  para2-review.html        — общая запоминалка по всей паре 2
  duties.html, routine.html, courtesy.html — справочные темы устава

tactics/
  index.html                — хаб предмета «Общая тактика» (темы добавляются)
  TEMPLATE-topic.html        — шаблон для новой темы, скопировать и заполнить
```

Каждая тема — самостоятельная HTML-страница, использующая общий движок
`shared/deck-engine.js`. Добавить новую тему = скопировать
`tactics/TEMPLATE-topic.html`, вписать свои карточки и добавить ссылку
на хабе предмета. Подробная инструкция — прямо в комментариях шаблона.

## Как устроена тема

На каждой теме — три режима:

- **Конспект** — все термины читаемым списком, со схемами (если есть) —
  для чтения перед тренировкой.
- **Тренажёр** — вопросы вперемешку (термин→определение, определение→термин,
  верно/неверно), без ограничения по времени.
- **Проверка знаний** — те же вопросы, но на время и с итоговой оценкой 2–5.

Вопросы и варианты ответов каждый раз собираются заново; темы, в которых
были ошибки, выпадают чаще. Прогресс хранится в `localStorage` браузера.

## Домашние задания

Список — на главной странице (`index.html`), в массиве `HOMEWORK` прямо
в коде страницы:

```js
var HOMEWORK = [
  { id:'hw1', due:'2026-09-10', from:'после пары 1 · Устав',
    text:'Текст задания...' },
  ...
];
```

Чтобы добавить новое задание — допишите объект в этот массив (`id` —
уникальный, `due` — дата в формате `ГГГГ-ММ-ДД`). Отметка «выполнено»
сохраняется только в браузере того, кто её поставил — список не общий
для всех посетителей (сайт статичный, без сервера, поделиться живым
списком между разными людьми без бэкенда нельзя).

## Как выложить на Yandex Cloud (Object Storage)

### Шаг 1. Создать бакет

1. Консоль → Object Storage → **Создать бакет**.
2. Имя — латиницей, например `zachet-vuc-2026`. Попадёт в адрес сайта.
3. **Доступ на чтение объектов — публичный.** Без этого сайт не откроется.
4. Размер — 1 ГБ с большим запасом (весь сайт — меньше 300 КБ).

### Шаг 2. Загрузить файлы

Загрузите **всю папку целиком**, сохраняя структуру (`shared/`, `ustav/`,
`tactics/` — как подпапки внутри бакета, `index.html` и `error.html` —
в корне). В консоли Object Storage это делается через «Загрузить» →
выбрать папку, либо перетаскиванием — структура вложенности сохранится.

### Шаг 3. Включить хостинг сайта

Бакет → **Настройки** → **Веб-сайт** → **Хостинг**:

- Главная страница: `index.html`
- Страница ошибки: `error.html`

Сохранить — появится адрес вида `https://zachet-vuc-2026.website.yandexcloud.net`.

### Обновление сайта

Загружайте изменённые файлы поверх старых (сохраняя те же пути в бакете).
Если браузер показывает старую версию — `Ctrl + F5`.

### Через AWS CLI вместо консоли

```bash
aws --endpoint-url=https://storage.yandexcloud.net s3 sync . s3://zachet-vuc-2026/ \
  --exclude ".git/*" --exclude ".claude/*"
```

`s3 sync` загрузит всю папку разом, сохранив структуру подпапок.

### Свой домен (по желанию)

1. Имя бакета должно точно совпадать с доменом.
2. CNAME на `<домен>.website.yandexcloud.net`.
3. Сертификат — через Certificate Manager, привязать в настройках бакета.
